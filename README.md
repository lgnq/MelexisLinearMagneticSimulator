# Melexis FAE 直线位移磁场仿真工具 (Magpylib PWA)

## GitHub Pages 快速部署指南
1. 在 GitHub 上新建一个仓库（例如 `melexis-magsim`，建议设为 Public）。
2. 解压本压缩包，将根目录下的 `index.html`、`manifest.json` 和 `sw.js` 上传至仓库根目录。
3. 打开仓库的 **Settings -> Pages**，在 **Branch** 下选择 `main` 分支与 `/ (root)` 目录并点击 **Save**。
4. 等待约 1 分钟即可通过 `https://<你的用户名>.github.io/melexis-magsim/` 访问。

## iPhone 端免安装全屏使用
1. 使用 iPhone 自带 **Safari** 浏览器打开上述 GitHub Pages 网址，等待提示「Magpylib 引擎就绪」。
2. 点击底部工具栏的 **「分享」按钮（↑）** -> 选择 **「添加到主屏幕」** -> 点击 **「添加」**。
3. 之后从桌面图标启动即可享受免 App Store、全屏原生体验与完整离线计算能力。
